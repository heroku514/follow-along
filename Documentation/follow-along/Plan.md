# Plan - Follow Along

## Goal

Ship a free offline line that a child and a grandparent tap in the same order, in type large enough to read across a table.

## Approach

1. Confirm App Store Connect has no rejected app waiting.
2. Build Follow Along in Expo: four lines, three buttons, and a saved place in the line.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.

## Why this app

Picture lists, outing plans, dice, dinner answers, household places, and tapped sentences are already in this pipeline. Seating puzzles, turn pickers, and visual timers already fill the store. This one is a short line to copy together.
